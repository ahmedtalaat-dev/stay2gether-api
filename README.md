# Stay2Gether API

**Stay2Gether API** is the backend service of Stay2Gether, a modern social media platform designed to connect people and encourage social interaction.

It provides a RESTful API responsible for handling application logic, authentication, data management, and communication between the frontend and backend.

## 🚀 Features

- User authentication and authorization
- User registration and login
- User profile management
- Create, update, and delete posts
- Like and comment on posts
- Follow and unfollow users
- User discovery and search
- Messaging and notifications
- API validation and error handling
- Secure API endpoints
